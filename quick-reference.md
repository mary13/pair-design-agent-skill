# Pair Design Quick Reference

**One-page cheat sheet for collaborative design sessions**

---

## 🎯 The Golden Rule

**NEVER DUMP MULTIPLE SCREENS/ARTIFACTS AT ONCE**

Work one step at a time. Show, review, iterate, next.

---

## 👥 Roles

| Gen (AI) | Synth (Human) |
|----------|---------------|
| Propose options | Frame problem |
| Generate artifacts | Give feedback |
| Ask before deciding | Make decisions |
| Build incrementally | Keep on track |

---

## ✅ Core Agreements

### Gen Must:
- [ ] Work one step at a time
- [ ] Show work as you go
- [ ] Never dump multiple screens
- [ ] Ask before major decisions
- [ ] Swap roles when needed

### Synth Must:
- [ ] Frame the problem clearly
- [ ] Give feedback on each step
- [ ] Make decisions when options presented
- [ ] Keep us on track

### Both Must:
- [ ] Progressive disclosure
- [ ] User-centered design
- [ ] Iterate based on feedback
- [ ] Document as we build

---

## 🚨 Red Flags - STOP if:

- ⛔ Multiple screens appear without approval
- ⛔ Major decisions made without discussion
- ⛔ Work proceeds without feedback
- ⛔ Requirements assumed, not confirmed
- ⛔ Scope creeping beyond current focus

---

## 🔄 The Workflow Loop

```
1. FRAME     → Synth defines the problem
2. GENERATE  → Gen creates ONE artifact
3. REVIEW    → Synth gives feedback
4. ITERATE   → Refine based on feedback
5. DOCUMENT  → Capture decision
6. NEXT      → Move to next artifact
```

Repeat until complete.

---

## 💬 Common Phrases

### Starting a Session
- "Let's use Pair Design methodology"
- "I'll be synth, you be gen"
- "Here's what I need to design..."

### During Work (Synth)
- "Show me just the first screen"
- "Before you build that, let me clarify..."
- "That looks good, let's move to the next one"
- "Let me give you feedback on this before continuing"

### During Work (Gen)
- "Before I create this, should I...?"
- "Here are two options - which direction?"
- "I've created [X]. Here's my rationale..."
- "Ready for the next screen, or should I revise this?"

### Catching Violations
- "Hold on - one screen at a time please"
- "Let's follow Pair Design agreements"
- "Show me the first one, we'll get to the others"

---

## 📋 Decision Documentation

Every significant decision needs:

```
Context:      Why was this needed?
Decision:     What did we choose?
Rationale:    Why this over alternatives?
Alternatives: What else did we consider?
Consequences: What are the trade-offs?
```

---

## ✨ Success Indicators

You're doing it right when:
- ✓ One artifact per iteration
- ✓ Every artifact reviewed before next
- ✓ Decisions documented with rationale
- ✓ Work flows steadily, not rushed
- ✓ Both roles feel collaborative

---

## ⚠️ Common Pitfalls

| Problem | Solution |
|---------|----------|
| Too slow | Check: specific feedback? Prompt decisions? |
| Directionless | Synth: Frame problem more clearly |
| Too many options | Gen: Present 2-3 max, recommend one |
| Revisiting decisions | Document immediately with rationale |
| Scope creep | Note for later, stay focused |

## 📝 Quick Session Setup

```
1. [ ] Roles assigned (who is synth/gen?)
2. [ ] Problem framed (what are we designing?)
3. [ ] Context shared (users, constraints, goals)
4. [ ] Success criteria defined
5. [ ] First artifact identified
6. [ ] Agreements acknowledged
```

---

## 🔧 Troubleshooting Quick Fixes

**"We're going too fast"**
→ Slow down. Review each artifact thoroughly.

**"We're going too slow"**
→ Make faster decisions. Trust you can iterate.

**"I want to see multiple options"**
→ Request them one at a time, review each separately.

**"AI made multiple screens"**
→ "Stop. Show me just the first one."

**"Can't decide between options"**
→ Use "which is easiest to change later?" as tiebreaker.

## 📊 Example Session Flow

```
Synth: "I need a login screen. Users should be able
       to sign in with email or social accounts."

Gen:   "Should I start with the form layout or
       the social button arrangement?"

Synth: "Form layout first."

Gen:   [Creates single login form screen]
       "Here's the form with email/password fields
       and social buttons below. Rationale: Form
       primary, social secondary..."

Synth: "Good. Move social buttons to top - they're
       the preferred method."

Gen:   [Shows revised version]
       "Updated. Ready for password reset screen?"

Synth: "Yes, next screen."
```
